# openCypher grammar and generated parser

- **Grammar:** `Cypher.g4`, the openCypher **M23** ANTLR4 grammar, downloaded unmodified from
  https://s3.amazonaws.com/artifacts.opencypher.org/M23/Cypher.g4 (linked from https://opencypher.org/resources/).
  SHA-256 `044d58feaccb263f2ec75f181f0f3153e8715b5013fc691d21da22592a58d62a`. Kept byte-for-byte (`.gitattributes`: `-text`).
- **License:** Apache License 2.0 (the header of `Cypher.g4`, © Neo Technology / the openCypher community). Its attribution
  notice asks that derivative work not approved by the openCypher Implementers Group not be described as "Cypher" or
  "openCypher": TemporalGraph.Query is a query engine for **a subset** of openCypher, and the grammar itself is unchanged.
- **Generated code:** `../Generated/` (CypherLexer, CypherParser, CypherVisitor, CypherBaseVisitor), namespace
  `TemporalGraph.Query.Parsing`, generated by the **ANTLR 4.13.1** tool (`antlr-4.13.1-complete.jar`, BSD-3-Clause) with
  `-Dlanguage=CSharp -visitor -no-listener`. It is committed, so the build needs no Java.
- **Runtime:** NuGet `Antlr4.Runtime.Standard` **4.13.1** (BSD-3-Clause), the same version as the tool.
- **Regenerate** (needs Java 11+ and the tool jar from https://www.antlr.org/download/antlr-4.13.1-complete.jar or Maven
  Central `org.antlr:antlr4:4.13.1`, complete jar):
  `pwsh tools/grammar/generate.ps1 -Jar <antlr-4.13.1-complete.jar> [-Java <java>]` or `sh tools/grammar/generate.sh <jar> [java]`.
